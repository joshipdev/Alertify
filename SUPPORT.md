# Getting help

Before asking for help:

1. Review the setup and troubleshooting sections in [README.md](./README.md) and [README_FIREBASE_SETUP.md](./README_FIREBASE_SETUP.md).
2. Check existing GitHub issues for the same problem.
3. Confirm whether the problem is in the Flutter app, Firebase configuration or rules, Android build, or ESP32 hardware/firmware.

For a reproducible defect, open a bug report using the issue form and include the steps, expected behavior, actual behavior, and relevant environment details.

For a feature proposal, use the feature request form. For general questions, use GitHub Discussions if enabled; otherwise open an issue with enough context for maintainers to route it.

Do not post passwords, API credentials, Firebase configuration secrets, personal information, or private database contents. Security vulnerabilities should be reported privately as described in [SECURITY.md](./SECURITY.md), not in an issue.

This project is maintained on a best-effort basis; support response times are not guaranteed.
